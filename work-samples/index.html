Larkspur Labs · Resource Library nav analysis1 / 11

Section 1 · Overview

Last year's report found the Resource Library had the fewest dropdown clicks, despite its content being the most viewed.

Objective

Find ways to raise engagement with the Resource Library section of the main navigation.

Answered using this year's GA4 data, compared against last year's report, plus results from three recent A/B tests on the nav.

Questions this analysis answers

  1. 01
    Should the nav hierarchy be tested, based on click behavior and recent A/B tests?
  2. 02
    Which recommendations are most likely to improve Resource Library nav engagement?
  3. 03
    What does this year's data show versus last year's report?
Larkspur Labs · Resource Library nav analysis2 / 11

Section 1 · Snapshot

The Resource Library's share of nav clicks is still the lowest of the three dropdowns, even though it's still the most-viewed content.

  1. 01
    Test setup unknowns. The CTA copy test reported a clear winner, but we're not yet confident it was configured as intended. The styling tests produced no winner.
  2. 02
    Two-step drop-off. The Resource Library is the least-opened dropdown, and once opened it still has the lowest link-click rate (31% vs. 44% for Product and 37% for Company).
  3. 03
    Device differences. On mobile, the footer now carries more nav clicks than the primary nav. Mobile users also need an extra step to reach Resource Library links.

Section 5 · Answers + recommendations

Should the nav hierarchy change? It's worth testing directly, given the multi-step drop-off.

  1. 01
    Micro-styling isn't the issue. The styling tests didn't move results, and the copy test needs a clean rerun. Naming and ordering haven't been tested yet.
  2. 02
    The gap shows up at two steps. Fewer opens, then fewer clicks once open. Naming and placement tests address the first step; menu content addresses the second.

Our recommendation

  1. Confirm the copy result, and rerun the test first if needed.
  2. Run a desktop placement test next, to compare its impact against the copy test.
  3. Then run a desktop dropdown naming test.

Run one test at a time so each result can be trusted.

Larkspur Labs · Resource Library nav analysis10 / 11

Section 5 · Answers + recommendations

Recommendations to improve Resource Library nav engagement

  1. 01
    Rerun the CTA copy test. Confirm each variant renders its own copy, and add a secondary goal for clicks on the changed button.
  2. 02
    Run desktop-only nav tests. Placement in the primary nav, dropdown naming, then the layout of items inside the dropdown. One at a time.
  3. 03
    Run a mobile-only footer test. Add a clear Resource Library link to the footer, where mobile users already navigate.
  4. 04
    Extend copy testing to the other in-menu CTAs if the rerun confirms a winner.
  5. 05
    Promote top resources elsewhere, such as the sticky nav or homepage, where high-intent clicks hold steady.
  6. 06
    Pause micro-styling tests until the larger menu tests are done.
